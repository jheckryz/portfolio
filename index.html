Project details

AI-Driven Augmented Reality Hairstyle Recommendation System with Personalized Hair Analysis and Decision Support (Stylehᴀɪr)

Description
Stylehᴀɪr is a mobile app that analyzes a user’s face shape and hair characteristics with AI to recommend suitable hairstyles, explains why each one fits, and lets users preview them on their own face through real-time augmented reality. A companion web dashboard lets administrators manage the hairstyle catalog, user accounts, and feedback, helping barbershops and salons offer more confident, personalized consultations.
Objectives
  • Build a mobile app where users can capture or upload facial images for analysis, recommendations, and virtual previews.
  • Implement AI-based facial and hair analysis that detects face shape, facial features, hair type, and hair length.
  • Develop a recommendation engine that matches users to hairstyles based on their features and preferences.
  • Provide explainable decision support showing why each hairstyle was recommended.
  • Create an AR feature for previewing hairstyles on a photo or live camera view.
  • Design a user-friendly mobile interface for scanning, viewing results, and saving styles.
  • Build a web-based admin dashboard for managing hairstyles, users, and system activity.
  • Evaluate the system for functionality, accuracy, usability, explainability, and user satisfaction.
Technologies used
  • Kotlin
  • Android Studio
  • DeepAR
  • Google ML Kit Face Detection and Face Mesh
  • Next.js and React.js (admin dashboard)
  • Jetpack Compose
  • TensorFlow
  • Firebase
  • Visual Studio Code
